Ты, как опытный Senior Fullstack-разработчик и архитектор ИИ-систем, должен спроектировать и написать комплексный, структурированный промпт (техническое задание для генерации кода) для создания интерактивной веб-платформы "JUZBOOK" — "Smart-Книги" для подготовки к ЕНТ (ҰБТ). 

Проект создается строго с нуля в пустой папке. Используй create-next-app для инициализации. Структура проекта должна быть максимально чистой и модульной.

### Стек технологий:
* **Frontend**: Next.js (последняя стабильная версия, App Router), TypeScript, Tailwind CSS, Shadcn UI.
* **Backend / API**: Встроенные Serverless Route Handlers внутри Next.js (App Router API routes).
* **Database**: PostgreSQL (Prisma ORM для моделирования и миграций).
* **AI Integration**: OpenAI API (использовать `gpt-4o-mini` для быстроты и экономии токенов), библиотека `openai` или Vercel AI SDK.
* **State Management / Storage**: React Context / Zustand и LocalStorage (для симуляции авторизации и локальных состояний на демо-этапе).

### Архитектура и Структура Базы Данных (Prisma Schema):
Необходимо заложить следующие сущности:
1.  **User**: `id`, `email`, `password`, `name`, `role` (ENUM: 'USER', 'ADMIN'), `currentStreak` (Int), `lastLoginDate` (DateTime).
2.  **Subject**: `id`, `name` (12 обязательных предметов: География, Биология, Информатика, Химия, Дүниежүзі тарихы, Қазақстан тарихы, Ағылшын тілі, Физика, Орыс тілі мен әдебиеті, Құқық негіздері, Қазақ әдебиеті, Қазақ тілі).
3.  **Book**: `id`, `title`, `subjectId`.
4.  **Chapter (Тақырып)**: `id`, `title`, `content` (Markdown/Text), `bookId`, `order` (Int).
5.  **UserProgress**: `id`, `userId`, `chapterId`, `isCompleted` (Boolean), `updatedAt`.
6.  **Highlight**: `id`, `userId`, `chapterId`, `selectedText`, `color`, `createdAt`.
7.  **Note (Заметка)**: `id`, `userId`, `chapterId`, `selectedText` (optional), `noteText`, `createdAt`.

### Функциональные блоки интерфейса и логика разработки (Шаг за шагом):

#### 1. Стилистика и Дизайн (UI/UX)
* **Цветовая схема**: Глубокий темный фон (Dark mode по умолчанию), текст и ключевые элементы — светлые. Реализовать чистый переключатель Light/Dark mode (используя `next-themes`).
* **Типографика**: Использовать качественные, аккуратные шрифты. Заголовки — Serif-шрифт (например, Playfair Display или Merriweather), часть слов-акцентов в заголовках выделять курсивом (выборочно, не сплошняком). Основной текст — читабельный Sans-Serif (Geist, Inter).
* **Анимации**: Плавные, сдержанные (использовать Tailwind переходы или Framer Motion).
* **Адаптивность**: Идеальное отображение как на смартфонах, так и на десктопах.

#### 2. Главная страница (Лендинг)
* Никаких кнопок "Начать бесплатно" (платформа полностью бесплатная и открытая). Главная кнопка призыва (CTA) — **"Кіру / Войти"** или **"Каталогқа өту / В каталог"**.
* Краткое описание платформы: "JUZBOOK — ҰБТ-ға дайындалуға арналған интерактивті "Smart-Кітап" веб-платформасы".
* Сетка (Grid) из 12 обязательных предметов для быстрого перехода.

#### 3. Интерфейс Читателя (Reader Workspace)
* **Навигация**: Четкая иерархия: Слева — сайдбар с главами текущей книги, сверху — хлебные крошки (Пән -> Кітап -> Тақырып), по центру — область чтения.
* **Интерактивный Поп-ап (Text Highlighting)**: При выделении мышкой (highlight) или двойном клике (double click) по любому слову/предложению в тексте книги, всплывает Tooltip с двумя опциями:
    1.  *"ИИ Анықтамасы"*: Отправляет выделенный текст + контекст главы на API. ИИ (GPT-4o-mini) генерирует краткое, емкое объяснение на казахском/русском языке (в зависимости от языка текста).
    2.  *"Өз анықтамамды жазу" (Заметка)*: Открывает мини-форму ввода, где студент пишет свой комментарий. Текст сохраняется в БД и визуально подсвечивается маркером выбранного цвета.
* **Тақырыптық анықтама блогы**: В самом конце каждой главы (под текстом) находится большая текстовая область (Textarea) для ведения глобального личного конспекта по этой теме.

#### 4. Личный кабинет студента (User Profile & Notes Journal)
При входе под `student@juzbook.kz` отображается персональный дашборд:
* **Прогресс-бар**: Визуальный индикатор выполнения (от $0\%$ до $100\%$) по каждому предмету и книге на основе прочитанных глав.
* **Күнделікті стрик (Daily Streak)**: Логика расчета "активности". При первом входе (в самый первый день) счетчик строго равен **1 дню**. Система проверяет `lastLoginDate`. Если разница между текущим входом и предыдущим ровно 1 день — стрик увеличивается (`streak + 1`). Если разница больше 1 дня — стрик сбрасывается в 1.
* **Заметкалар журналы (Журнал заметок)**: Полноценный пустой экран, если заметок нет, который динамически заполняется по мере их создания. Отображает список всех сохраненных пользователем заметок и хайлайтов. **Критически важно**: Каждая заметка в списке является кликабельной ссылкой. При клике на нее пользователя автоматически перенаправляет на нужную книгу, конкретную главу, а страница плавно скроллится к выделенному слову.

#### 5. ИИ Тест Генератор (Context-based AI Quiz)
* Блок теста находится внизу страницы после текста главы.
* Перед началом теста пользователь выбирает настройки: Количество вопросов (5, 10, 15) и Уровень сложности (Жеңіл, Орташа, Қиын).
* **Интеграция ИИ**: Запрос к OpenAI API отправляет строгий `System Prompt`: *"Служи строго в качестве генератора тестов по предоставленному тексту. Тест должен состоять из [X] вопросов, уровень сложности [Y]. Вопросы должны быть исключительно по фактам из предоставленного контекста. Запрещено использовать внешние знания или информацию из других тем. Формат ответа — строго валидный JSON."*
* После завершения выводится красивый виузальный интерактивный отчет: какие ответы верны (зеленый), какие нет (красный), и итоговый балл.

#### 6. Помодоро Таймер (Pomodoro Timer)
* Плавающий виджет (Floating Widget) в углу экрана, доступный на любой странице.
* Должен работать строго по классическому циклу: **25 минут — сессия фокуса (Работа)**, после окончания которой автоматически или по клику включается **5 минут — сессия отдыха (Демалыс)**. Звуковое или визуальное уведомление по окончании таймера.

#### 7. Панель Администратора (Admin Control Panel)
При входе под `admin@juzbook.kz` открывается интерфейс управления контентом:
* **Full CRUD**: Возможность добавлять, редактировать названия и удалять Предметы, Книги и Главы.
* **Текстовый редактор**: Удобное текстовое поле (с поддержкой Plain text / Markdown) для быстрой вставки (Copy-Paste) больших объемов учебного материала в базу данных.
* **Визуальные инфобоксы (Callout / Alert Blocks)**: Инструмент в редакторе админа. Выделенный админом абзац можно обернуть в специальный шорткод или тег (например, `[danger]...[/danger]`), который на фронтенде отрендерится как виузально выделенный блок в рамке со значком "Маңызды, қарап ал!" или "ҰБТ-да жиі келеді".
